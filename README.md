# MEP 工具箱

機電工程日常會用到的計算工具，全部做成網頁。開啟連結就能用，不用安裝、不用登入，手機也能開。

**線上網址**：https://evan717717.github.io/mep-toolbox/

## 設計原則

這個站刻意做得很小、很無聊，因為工程工具最需要的是**十年後打開還能跑**。

1. **每支工具是一個獨立資料夾、一個 HTML 檔。** 沒有打包步驟、沒有 npm、沒有框架。
   直接用瀏覽器打開檔案就能跑，也可以整包下載帶去沒網路的工地。
2. **工具之間互不依賴。** 改壞一支不會影響其他支。
3. **首頁自動生成。** 工具清單集中在 `assets/tools.js`，新增工具不必動首頁 HTML。
4. **算式與來源一律寫在頁面上。** 工程計算的結果要能被查核，沒有出處的數字不能拿去用。
5. **計算條件寫進網址。** 貼連結給同事，對方看到的是同一組條件與同一個答案。

## 目錄結構

```
mep-toolbox/
├── index.html                      # 首頁（工具索引、搜尋、分類篩選）
├── assets/
│   ├── tools.js                    # 工具清單 — 唯一需要維護的資料來源
│   └── tokens.css                  # 共用色彩與字體變數
├── tools/
│   ├── manning-calculator/
│   │   └── index.html              # HYD-01
│   └── _template/
│       └── index.html              # 新增工具用的起始樣板
├── .github/workflows/
│   └── deploy-pages.yml            # push 到 main 就自動發布
├── .nojekyll                       # 讓 GitHub Pages 原樣輸出檔案
├── CONTRIBUTING.md                 # 新增工具的完整步驟
└── LICENSE
```

## 新增一支工具（三步）

```bash
cp -r tools/_template tools/你的工具名稱
```

1. 編輯 `tools/你的工具名稱/index.html`，把樣板裡標了 ①②③④ 的地方換成你的內容。
2. 打開 `assets/tools.js`，照著現有格式加一筆記錄。
3. Commit 並 push 到 `main`，約一分鐘後自動上線。

完整說明與檢查清單見 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 本地預覽

直接用瀏覽器打開 `index.html` 就能看。想要跟線上完全一致（相對路徑行為一樣），起一個本機伺服器：

```bash
python3 -m http.server 8000
# 瀏覽器打開 http://localhost:8000
```

## 分享給別人

- **傳整個工具箱**：把首頁網址貼給對方。
- **傳一組特定計算**：在工具頁面按「複製分享連結」，對方打開會看到你當下的輸入條件與結果。
- **放進投影片或報告**：按「列印 / 存 PDF」，版面已針對白底列印調整過。
- **嵌進 Notion 或 Confluence**：貼上工具網址，選 Embed。
